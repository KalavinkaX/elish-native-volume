# 3.2.0-stability-test1：后台稳定性预发布

本版降低后台空闲开销，给音效故障增加退避，修正暂停会话资源保留，并停止隐藏界面下无用的定时任务。保留 3.1.0 的全局 0–100、低档扬声器曲线、原生分应用滑块与长按加速。

- 后台从固定 50ms 检查改为活跃约 100ms、配置空闲约 1 秒、无规则/禁用约 2 秒。面板保存设置会通知后台立即检查。
- 音效创建/更新/释放失败按 1–30 秒退避，防止短周期重试；旧 session 所有者释放失败时阻止新 UID 使用旧句柄。
- 暂停不再无限续期：约 5 秒后申请释放；明确停止不套用缺失快照宽限。
- 关闭面板后排空最后提交值并取消客户端定时任务，音频后台继续独立运行。
- 稳定状态心跳约 30 秒，状态变化立即写入。

83 项主机回归测试、精确目标 ROM ABI、APK 签名与 zipalign 检查通过；签名与 3.1.0 相同。**本版尚未在设备实测**。新开始播放时，保存的衰减可能等待下一轮空闲检查（约 1 秒）才附加；请先在低系统音量下测试首音、暂停恢复及 100% 切换。

仅适用于 Xiaomi Pad 5 Pro `elish`，`lineage-24.0-20261013-UNOFFICIAL-elish`（LineageOS 24 / Android 17），精确 ROM 哈希见 README。LSPosed 使用原有 SystemUI 和 Android 两个作用域。

配套覆盖安装本版 Magisk ZIP 与 LSPosed APK，然后重启；请核对 SHA256SUMS。源码 ZIP 不需刷入。源码不附签名私钥、密码、SDK 或 ROM。

详细方案与设备验收步骤见 `docs/STABILITY-3.2.md`。这些修复不修改 CPU、电压、温控、充电参数，不能解释或修复此前的 CPU 焊点/无法开机故障。
