# 设备验收

当前作者反馈3.1.0-key-test1效果良好；只有elish指定ROM已验证。

1. 重启后未播放的应用不列出，播放后显示原色图标，暂停后隐藏，恢复播放保留设置。
2. 两个能同时播放的应用分别设30%/70%，全局媒体索引不变；同UID合并。
3. 多次在30%与100%间拖动，无短暂突增；关闭面板、息屏、后台播放及重启后规则保持。
4. 单按一档、快速单按一档；扬声器音量高于10长按后按时长变为2/3档；松手停止，低档恢复精调。
5. 通话、通知、蓝牙及滑块操作不触发按键加速。
6. 验证取消Android作用域只关闭加速，停用后台能释放它持有的音效。

主机测试：78项，覆盖协议边界/身份、规则隔离、会话生命周期、增益换算、100%对象复用、客户端合并与按键策略。不能替代Android SELinux、Compose、系统按键投递与真实音频测试。
