# 【开源分享】小米平板5 Pro刷LineageOS后的音量补完：原生分应用音量＋低音量优化＋长按加速

我的小米平板5 Pro（elish）刷了LineageOS 24 / Android 17之后，遇到几个音量上的小遗憾：最低一档还是偏大，想更细地调；同时播放两个应用时，又只能改系统总音量。

于是边测试边做了这个 Elish Native Volume，开发过程中有AI辅助，经过多轮实机测试，目前我这台设备用起来已经比较满意，整理源码分享一下。

目前包含：

• 全局媒体音量0–100细调，并优化扬声器低音量曲线。这里是101个整数索引，不是数学意义连续无级，也不是响度线性百分比。
• 原生分应用音量：按音量键还是系统小窗口，点“更多”才出现应用滑块，直接用系统原生布局，没有另一个浮窗。
• 只显示正在播放的应用，保留原色图标；暂停后隐藏，设置会记住。
• 关闭音量面板后后台继续工作，不会因为关面板就重置应用音量；调到100%也不再在端点反复卸载音效。
• 长按音量键渐进加速：单按一档，按住0.8秒后两档、1.8秒后三档；0–10档仍一档精调。快速调大致位置，松手后再单按微调。
• 新界面不反复申请root，也不需要旧版无障碍服务。

分应用滑块控制的是“在系统总音量之上再衰减多少”：100%不额外衰减，0%为接近静音。如果两个播放器互相抢音频焦点导致其中一个暂停，需要先让它们能同时播放；模块不负责解除音频焦点限制。同UID应用也不能拆成两个独立声音。

【适配范围一定看】
目前只在我的小米平板5 Pro（elish）验证，ROM是 lineage-24.0-20261013-UNOFFICIAL-elish，LSPosed 2.2.1。不是MIUI/HyperOS通用模块，也没验证其他小米平板或其他构建。它会核对SystemUI/services.jar哈希，换ROM后可能需要重新适配。

【安装】
下载同版Magisk ZIP＋LSPosed APK，分别安装。在LSPosed启用后，勾选“系统界面”和“系统框架 / Android”，然后重启。用过旧浮窗版的，先关旧无障碍服务。升级不用清空音量规则。

长按加速目前只针对平板扬声器媒体音量，蓝牙、通话、通知等保持系统行为。想关闭加速，可以只取消Android作用域并重启，保留SystemUI继续用分应用滑块。
